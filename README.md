# Contact Book

A simple Flask contact book application.

## Setup

1. Create a virtual environment:

   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the app:

   ```bash
   python run.py
   ```

4. Open `http://127.0.0.1:5000` in your browser.
